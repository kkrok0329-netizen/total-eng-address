# TOTAL ENG 현장주소 V3.6.4

V3.5.7 화면과 설정 방식을 유지하면서 Google Sheets 공동 현장목록, 자동백업, 안전 삭제를 연결한 PWA입니다.

## 주요 기능

- 오른쪽 위 ⚙️ 설정에서 다크모드 켜기/끄기
- 현장 추가·수정·삭제 즉시 모든 직원에게 반영
- 삭제 전 확인창과 현장명 직접 입력으로 실수 방지
- 추가·수정·삭제 직전 전체 현장목록을 `자동백업` 탭에 저장
- 최근 20개 전체 백업본 자동 유지
- 휴대폰 저장본을 먼저 표시하고 Google Sheets를 뒤에서 갱신하는 빠른 로딩
- 티맵, 카카오내비, 네이버지도, 현대차, 기아차 연결
- Google Sheets 연결 실패 시 저장본 또는 내장 백업 표시
- 업데이트 후 최초 1회에만 이번 업데이트 내용 팝업 표시

## 삭제 방법

1. 앱 오른쪽 위 ⚙️ 설정을 누릅니다.
2. 삭제할 현장을 누른 뒤 `현장 삭제`를 누릅니다.
3. 첫 확인창에서 확인합니다.
4. 표시된 현장명을 똑같이 입력해야 삭제됩니다.

삭제 직전 전체 현장목록은 Google Sheets의 `자동백업` 탭에 남습니다.

## 배포 순서

삭제와 자동백업이 포함된 새 Google Apps Script 주소에 연결되어 있습니다. 이 웹앱 파일을 GitHub Pages에 업로드하면 됩니다.

직원들이 앱을 다시 설치할 필요는 없습니다. 앱을 완전히 닫았다가 다시 열면 V3.6.4로 갱신됩니다.

## 보안 안내

현재 Google Apps Script 주소는 로그인과 승인 절차 없이 등록·수정·삭제할 수 있도록 공개되어 있습니다. 회사 내부에서만 앱 주소를 공유하세요.
