# TOTAL ENG 현장주소 V3.6.1

기존 V3.5.7 화면과 설정 방식을 유지하면서 Google Sheets 공동 현장목록을 연결한 PWA입니다.

## 주요 기능

- 오른쪽 위 ⚙️ 설정에서 다크모드 켜기/끄기
- 현장명, 구분(일반현장/쿠팡), 주소, 기타 메모 등록
- 등록 즉시 Google Sheets에 저장되어 모든 직원에게 표시
- 기존 현장 정보 수정 즉시 전체 반영
- 티맵, 카카오내비, 네이버지도, 현대차, 기아차 연결
- Google Sheets 연결 실패 시 내장된 74개 현장 백업 표시

## 사용 방법

1. 앱 오른쪽 위 ⚙️ 설정을 누릅니다.
2. `+ 주소 추가` 또는 수정할 현장을 누릅니다.
3. 내용을 입력하고 저장합니다.
4. 직원들은 앱의 `새로고침`을 누르거나 앱을 다시 열면 변경 내용을 확인할 수 있습니다.

직원들이 앱을 다시 설치할 필요는 없습니다. 이번 V3.6.1 파일을 GitHub에 한 번 업로드한 뒤부터 현장 데이터는 Google Sheets를 통해 갱신됩니다.

## 배포

GitHub Pages에서 `main / (root)`로 게시합니다.

## 보안 안내

현재 Google Apps Script 주소는 로그인과 승인 절차 없이 등록할 수 있도록 공개되어 있습니다. 링크를 알게 된 외부인도 등록을 시도할 수 있으므로 회사 내부에서만 앱 주소를 공유하세요.
