TOTAL ENG V3.7.0 공용 주소록 적용

1. 구글 시트는 TOTAL ENG 소유자 계정으로 엽니다.
2. 확장 프로그램 → Apps Script. 현재 Code.gs 내용을 별도로 복사해 백업합니다.
3. 전달받은 Code_V3.7.0.gs 내용을 전체 복사하여 기존 Code.gs 내용을 교체하고 저장합니다.
   기존 코드에 추가로 붙여넣으면 같은 함수가 중복되므로 반드시 교체합니다.
4. 배포 → 배포 관리 → 현재 앱이 사용하는 웹 앱의 연필(수정) → 버전: 새 버전 → 배포.
   기존 웹 앱 배포를 수정해야 /exec 주소가 유지됩니다. 실행 사용자: 나, 접근: 모든 사용자 설정 유지.
   새 배포를 만들어 URL이 달라졌다면 js/app.js의 API_URL도 새 /exec 주소로 바꿔야 합니다.
5. TOTAL_ENG_Address_V3.7.0_GitHub.zip을 풀어 안의 파일·폴더를 GitHub 저장소 최상단에 덮어 올립니다.
6. 배포가 완료되면 앱을 다시 열어 V3.7.0 확인 → 공용 주소록 → 새로고침.
   최초 연결 시 공용주소록 탭이 자동 생성됩니다. 첫 등록 시 주소록변경이력 탭도 생성됩니다.
7. 테스트 연락처를 하나 등록하고 다른 직원 휴대폰에서 새로고침하여 공유를 확인합니다.
   전화/문자는 연결된 앱에서 최종 통화·전송을 누릅니다.

분류: 우리회사 / 현장 / 협력사.
필수: 이름, 전화번호. 선택: 업체명, 직책, 현장명, 메모.
공용주소록 탭은 열 이름과 순서를 바꾸지 마세요.
주소록은 저장본을 오프라인으로 볼 수 있지만 추가·수정·삭제는 서버 연결이 필요합니다.
전화번호 중복은 확인 후 계속 등록할 수 있습니다.
같이 편집한 경우 새로고침 후 다시 저장합니다.
이 코드는 기존 배포용 Code.gs를 바탕으로 현장 등록·삭제·백업 기능을 유지해 작성했습니다.
그 뒤 Apps Script를 직접 변경한 내용이 있다면 교체 전 별도로 반영해야 합니다.

공용 전화번호는 기존 현장 데이터처럼 앱 링크를 아는 사람이 조회·변경할 수 있습니다.
등록하는 사람의 동의를 받은 업무 연락처만 넣고 앱 링크는 회사 내부에 공유하세요.
전화번호 실데이터나 가상 연락처는 이번 패키지에 미리 등록하지 않았습니다.
