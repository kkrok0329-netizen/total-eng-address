TOTAL ENG 업무수첩 V3.8.2

V3.8.1의 연락처 공유·저장, 전체 디자인, 새 앱 아이콘, 부서 필터를 모두 포함합니다.

추가 변경
- 설정의 현장주소 관리 목록 제거. 설정에는 업데이트·다크모드 기능이 남습니다.
- 현장주소 탭의 목록 위에 '+ 현장 추가' 버튼 배치.
- 현장 선택 → 상세 화면 제목 옆 '수정' → 기존 정보 편집 화면 연결.
- 편집 화면에서 기존과 동일하게 삭제 가능. 삭제 확인·자동백업 동작 유지.
- 미리보기에서는 추가·수정 화면만 열 수 있고 서버 저장·삭제는 차단합니다.

적용
1. TOTAL_ENG_Workbook_V3.8.2_GitHub.zip 압축 풀기.
2. 내용물만 GitHub 저장소 최상단에 업로드 → Commit changes.
   https://github.com/kkrok0329-netizen/TOTAL_ENG_Address_V3_5
3. 배포 후 앱 설정 → 업데이트 확인 → 하단 V3.8.2 확인.

이번 패치는 Apps Script 수정이 없습니다. 단, 이전 부서 기능용 Code_V3.8.0.gs 배포는 필요합니다.
공유·저장은 내부 메모를 제외하며, 연락처 저장은 .vcf 파일을 열어 가져오는 방식입니다.
이전 버전 적용 안내는 V3.8.1_적용방법.txt를 참조하세요.
