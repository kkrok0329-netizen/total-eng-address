TOTAL ENG 업무수첩 V3.8.1

이번 변경
- 연락처에 전화 / 문자 / 공유 / 연락처 저장 버튼 추가.
- 공유: 휴대폰 공유 메뉴를 사용하고 미지원 시 텍스트 복사, 복사도 불가하면 수동 복사 안내.
- 저장: 한 명씩 .vcf 연락처 파일로 내려받습니다. 다운로드한 파일을 열고 새 연락처 추가/가져오기를 진행하세요.
  웹 앱이 휴대폰 주소록에 직접 또는 자동 저장하지는 않습니다. 기기별 파일 처리 화면은 다를 수 있습니다.
- 공유·파일 저장 모두 내부 메모를 제외합니다. 이름, 직책, 전화번호, 업체, 부서, 현장 정보를 사용합니다.
- 기존 메인 상단 유지, 요청한 보조 문구 제거. 현장 카드·주소록·검색·필터·설정·입력 화면·다크모드 정돈.
- 외부 폰트/UI 라이브러리를 추가하지 않았습니다.
- 시트 데이터, 연락처 ID, 부서 정보, 삭제·백업 정책은 변경하지 않았습니다.

적용 방법
1. TOTAL_ENG_Workbook_V3.8.1_GitHub.zip 압축을 풉니다.
2. 폴더 자체가 아니라 내용물을 아래 저장소 최상단에 올립니다.
   https://github.com/kkrok0329-netizen/TOTAL_ENG_Address_V3_5
3. Commit changes 후 GitHub Pages 배포 완료를 확인합니다.
4. 앱 설정 → 업데이트 확인, 하단 V3.8.1 확인.
   https://kkrok0329-netizen.github.io/TOTAL_ENG_Address_V3_5/
5. 주소록에서 공유, 연락처 저장을 각각 확인합니다.

중요: 이번 공유/저장/디자인 패치는 Apps Script 수정이 없습니다.
단, 이전 부서 기능을 위한 Code_V3.8.0.gs를 아직 배포하지 않았다면 그 배포는 필요합니다.
기존 배포 주소를 유지하여 새 버전으로 배포하세요.

아이콘이 이전 모습으로 남으면 홈 화면 바로가기를 제거한 뒤 다시 추가할 수 있습니다.
로컬 미리보기는 서버 데이터 편집을 막았으며 실제 휴대폰의 주소록 가져오기까지 검증한 것은 아닙니다.
