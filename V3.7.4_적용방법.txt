V3.7.4 업체 자유 입력 + 자동 필터 통합

새 업체는 '업체·분류' 칸에 직접 입력하세요. 기존 업체는 자동완성 목록에서 선택할 수도 있습니다.
등록된 업체·분류를 기준으로 필터가 자동 생성됩니다.
띄어쓰기와 영문 대소문자, 전각/반각 차이만 있는 이름은 같은 업체로 표시·저장합니다.
예: 예인 시스템 → 기존 예인시스템 항목에 연결.
다른 업체 이름을 추측해 합치지 않고, 사람은 이름만 같다고 삭제/통합하지 않습니다.

사진 연락처 신규 등록 완료: 남정훈 과장님, 예인시스템(개인 이름 미표기), 김원진 대표님, 손진호 과장님.
전병진 책임님은 기존 연락처와 같아 중복 등록하지 않았습니다. 총 74개.

적용
1. Code_V3.7.4.gs 내용으로 Apps Script의 기존 Code.gs 전체 교체 후 저장.
2. 배포 → 배포 관리 → 기존 주소록 웹 앱 수정(연필) → 새 버전 → 배포.
   기존 배포 URL AKfycbwm6...XS/exec 를 유지합니다.
3. ZIP을 풀어 내용물만 TOTAL_ENG_Address_V3_5 저장소 최상단에 업로드 → Commit changes.
4. 배포 완료 후 앱 설정 → 업데이트 확인 → V3.7.4 확인.
5. 이전 버전에 머물면 아래 페이지에서 복구합니다.
   https://kkrok0329-netizen.github.io/TOTAL_ENG_Address_V3_5/recover.html

이번 Apps Script 업데이트 이후부터 새 업체를 추가할 때마다 코드를 다시 배포할 필요가 없습니다.
실제 휴대폰에서 업체 등록/전화/문자 동작은 배포 후 확인하세요.
