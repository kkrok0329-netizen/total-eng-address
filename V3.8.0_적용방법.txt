TOTAL ENG 업무수첩 V3.8.0

앱 이름: 업무수첩 / 현장 정보와 업무 연락처를 한곳에
현장 수 표시는 현장주소 탭 안으로 이동했습니다.
우리회사 전용 부서 필터: 경영지원, 전장사업부, 기계사업부, 프로그램사업부, 연구소.
우리회사 연락처 수정 화면에서만 부서 선택이 표시됩니다.
기존 앱에서 부서 없이 수정해도 서버에서는 기존 부서를 보존합니다.

시트는 이미 반영했습니다.
- 경영지원 3명 / 전장사업부 6명 / 기계사업부 4명 / 프로그램사업부 4명 / 연구소 1명
- 정기태 연락처 삭제(이력 보존), 김경록 주임님 추가, 우리회사 18명 / 전체 74개 유지
- 권병규 직책 부장님, '경영학 부장님'은 기존 권영학 부장님으로 해석해 배정

적용
1. Code_V3.8.0.gs로 Apps Script의 기존 Code.gs 전체를 교체하고 저장.
2. 배포 → 배포 관리 → 기존 주소록 배포 수정(연필) → 새 버전 → 배포.
   기존 AKfycbwm6...XS/exec 주소 유지.
3. ZIP을 풀어 내용물만 아래 저장소 최상단에 올리고 Commit changes.
   https://github.com/kkrok0329-netizen/TOTAL_ENG_Address_V3_5
4. 배포 완료 후 앱 설정 → 업데이트 확인 → 하단 V3.8.0 확인.
   갱신이 멈추면 https://kkrok0329-netizen.github.io/TOTAL_ENG_Address_V3_5/recover.html
5. 공용 주소록 → 우리회사 → 부서 필터 확인.

시트 '공용주소록'의 J열(부서), '주소록변경이력'의 L열(부서)이 추가됩니다.
기존 열 순서와 연락처 ID는 유지했습니다. 실제 연락처 명단은 ZIP에 포함하지 않습니다.
홈 화면의 기존 아이콘 이름은 휴대폰에 남을 수 있습니다. 새로 추가하면 업무수첩 이름을 사용합니다.

로컬 미리보기는 읽기 전용입니다. 실제 앱의 부서 조회·저장은 새 Apps Script 배포 이후 동작합니다.
