TOTAL ENG 현장주소 V3.6.8 적용 방법

1. ZIP을 압축 해제합니다.
2. GitHub total-eng-address 저장소의 맨 위(root)에서 Add file → Upload files를 누릅니다.
3. 압축 푼 폴더 자체가 아니라 안의 index.html, js, data, img 등 파일·폴더를 모두 끌어 넣습니다.
4. Commit changes를 누르고 GitHub Actions의 Pages 배포 완료를 기다립니다.
5. 앱을 닫았다가 다시 열어 하단 V3.6.8을 확인합니다.
6. 버전이 그대로라면 Chrome에서 기존 앱 주소를 열고 새로고침합니다.

Apps Script 재배포와 구글 시트 수정은 필요하지 않습니다.
