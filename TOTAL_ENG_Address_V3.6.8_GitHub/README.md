# TOTAL ENG 현장주소 V3.6.8

구글 시트 공동 현장관리 PWA입니다. 기존 등록·수정·안전삭제·자동백업·지도·다크모드를 유지합니다.

## 이번 변경

- 같은 건물의 층수·건물명 차이를 고려한 중복 경고(층/업체가 다르면 계속 저장 가능)
- 군포1 검색 별칭 및 ID31 즐겨찾기/최근 기록을 ID25 군포로 이전
- 시트 동기화 성공 시 삭제된 현장의 기기 기록 정리
- 설정에 동기화 상태 및 업데이트 확인 버튼
- 2026-10-15 최종 수정 기준 현장 76개 내장 백업

중복 경고는 현재 불러온 목록을 기준으로 하므로 동시 등록까지 완전히 막지는 않습니다.
군포1 외의 통합 현장은 별도로 ID 매핑을 추가해야 합니다.
공유된 같은 건물이라도 별도 업체일 수 있어 자동 삭제/통합은 하지 않습니다.

## 적용

GITHUB_UPDATE_GUIDE.txt를 따르세요. Apps Script 재배포는 필요 없습니다.
ZIP 압축을 푼 내용물을 GitHub 저장소 최상단에 업로드합니다.

현장목록 API는 기존 공개 등록 방식입니다. 앱 주소는 회사 내부에서 공유하세요.
