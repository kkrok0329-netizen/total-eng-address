TOTAL ENG 현장주소 V3.6.2 업데이트 순서

[먼저 Google Apps Script 업데이트]

1. Apps Script 편집기에서 기존 Code.gs 내용을 모두 지웁니다.
2. 제공된 새 Code.gs 내용을 붙여넣고 저장합니다.
3. 배포 → 배포 관리 → 기존 배포의 연필 버튼을 누릅니다.
4. 버전을 새 버전으로 선택하고 배포합니다.
5. 기존 웹 앱 주소는 그대로 사용합니다.

[그다음 GitHub 업데이트]

1. TOTAL_ENG_Address_V3.6.2_GitHub.zip의 압축을 풉니다.
2. GitHub의 total-eng-address 저장소를 엽니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 파일과 폴더 전체를 업로드합니다.
5. Commit message에 `자동백업과 안전 삭제 V3.6.2`라고 입력합니다.
6. Commit changes를 누릅니다.
7. 약 1~3분 후 앱을 완전히 닫았다가 다시 엽니다.
8. 화면 아래 버전이 V3.6.2이면 반영 완료입니다.

V3.6.2 변경 내용

- 현장 삭제 기능
- 확인창 + 현장명 직접 입력으로 실수 삭제 방지
- 추가·수정·삭제 직전 전체 목록 자동백업
- 최근 20개 백업본 유지
- 저장된 목록을 먼저 표시하여 앱 로딩 속도 개선

직원들이 앱을 다시 설치할 필요는 없습니다.
