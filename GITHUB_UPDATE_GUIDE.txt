TOTAL ENG 현장주소 V3.6.3 GitHub 업데이트 순서

Google Apps Script 삭제·자동백업 서버는 이미 새 주소로 배포되었습니다.
이제 GitHub 파일만 교체하면 됩니다.

1. TOTAL_ENG_Address_V3.6.3_GitHub.zip의 압축을 풉니다.
2. GitHub의 total-eng-address 저장소를 엽니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 파일과 폴더 전체를 업로드합니다.
5. Commit message에 `삭제 서버 연결 V3.6.3`이라고 입력합니다.
6. Commit changes를 누릅니다.
7. 약 1~3분 후 앱을 완전히 닫았다가 다시 엽니다.
8. 화면 아래 버전이 V3.6.3이면 반영 완료입니다.

V3.6.3 변경 내용

- 새 Google Apps Script 주소 연결
- 현장 삭제 및 자동백업 서버 연결 확인
- 현재 Google Sheets 현장 77개 오프라인 백업 반영
- 빠른 로딩 방식 유지

직원들이 앱을 다시 설치할 필요는 없습니다.
