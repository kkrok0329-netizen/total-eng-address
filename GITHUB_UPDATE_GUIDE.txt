TOTAL ENG 현장주소 V3.6.1 GitHub 업데이트 방법

1. TOTAL_ENG_Address_V3.6.1_GitHub.zip의 압축을 풉니다.
2. GitHub의 total-eng-address 저장소를 엽니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 파일과 폴더 전체를 업로드합니다.
5. Commit message에 `Google Sheets 연동 V3.6.1`이라고 입력합니다.
6. Commit changes를 누릅니다.
7. 약 1~3분 후 앱을 완전히 닫았다가 다시 엽니다.
8. 화면 아래 버전이 V3.6.1이면 반영 완료입니다.

이 업데이트는 V3.5.7의 설정창과 다크모드 방식을 그대로 유지합니다.
업데이트 후 직원들이 앱을 다시 설치할 필요는 없습니다.

현장 추가·수정 방법

1. 앱 오른쪽 위 ⚙️ 설정을 누릅니다.
2. `+ 주소 추가` 또는 기존 현장을 누릅니다.
3. 현장명, 구분, 주소, 기타 메모를 입력하고 저장합니다.
4. Google Sheets에 즉시 저장되며 다른 직원은 새로고침 후 확인할 수 있습니다.
