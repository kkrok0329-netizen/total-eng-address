TOTAL ENG 현장주소 V3.6.7 GitHub 업데이트 순서

1. TOTAL_ENG_Address_V3.6.7_GitHub.zip의 압축을 풉니다.
2. GitHub의 total-eng-address 저장소를 엽니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 파일과 폴더 전체를 업로드합니다.
5. Commit message에 `검색 및 중복 경고 V3.6.7`이라고 입력합니다.
6. Commit changes를 누릅니다.
7. 약 1~3분 후 앱을 완전히 닫았다가 다시 엽니다.
8. 화면 아래 버전이 V3.6.7이면 반영 완료입니다.

V3.6.7 변경 내용

- 현대차·기아차 버튼 제거
- 지역·현장명·주소·메모의 띄어쓰기 및 다중 단어 검색 개선
- 같은 현장명 또는 주소 저장 전 중복 경고
- 설치 앱 새 버전 감지 후 자동 새로고침
- 설치 시작 주소와 주요 파일 캐시 갱신 강화
- 업데이트 후 처음 실행할 때만 업데이트 내용 팝업 표시
- 확인 후 같은 버전에서는 다시 표시하지 않음
- 다음 버전으로 바뀌면 새 안내를 다시 1회 표시
- 현장 삭제, 자동백업, 빠른 로딩 안내 포함
