앱이 새로워졌어요

이번 업데이트에서 달라진 내용을 확인해 주세요.

  • TOTAL ENG 업무수첩현장주소와 공용 주소록을 담는 앱 이름으로 바꿨습니다.
  • 우리회사 부서 필터경영지원·전장사업부·기계사업부·프로그램사업부·연구소로 구분합니다.
  • 연락처 공유·저장연락처를 공유하거나 휴대폰으로 가져올 수 있는 파일로 저장합니다. 내부 메모는 제외됩니다.
  • 화면 디자인 정돈현장 카드·공용 주소록·검색·설정 화면을 통일된 디자인으로 개선했습니다.

이 안내는 이번 버전에서 한 번만 표시됩니다.

아이폰 홈 화면에 추가

카카오톡·네이버 앱 안에서 열었다면 먼저 링크를 복사하고 Safari에서 열어 주세요.

  1. Safari에서 이 앱 주소를 엽니다.
  2. 공유 버튼(네모 위로 화살표)을 누릅니다. 보이지 않으면 페이지 메뉴를 펼쳐 공유를 찾으세요.
  3. 공유 메뉴를 아래로 내려 홈 화면에 추가를 선택합니다. 없으면 동작 편집에서 추가하세요.
  4. 웹 앱으로 열기 항목이 있으면 켜고 추가를 누릅니다.
  5. 홈 화면의 업무수첩 아이콘으로 실행합니다.

회사에서 관리하는 기기는 홈 화면 추가가 제한될 수 있습니다.
